# Соедини точки

React + Vite приложение для создания connect-the-dots изображения из загруженного фото.

## Деплой на Vercel

1. Создай репозиторий на GitHub.
2. Загрузи в него файлы из этой папки.
3. Открой Vercel и импортируй репозиторий.
4. Настройки Vercel:

```text
Build Command: npm run build
Output Directory: dist
```

## Локальный запуск

```bash
npm install
npm run dev
```

## Проверка сборки

```bash
npm run build
```
